## BookDuty
<img width="35%" alt="logo-on-brand" src="https://github.com/user-attachments/assets/7878f031-831c-431f-abe5-e9027d8ef7eb" />

사회복무요원으로 근무하며 기관 도서관을 관리하는 관리자 전용 웹 서비스입니다.

## 레포지토리

| 레포 | 역할 |
|---|---|
| [backend](https://github.com/Social-Agent-Library-Management/backend) | 도서·소장본·대출·반납·연체를 처리하는 API 서버 (OpenSearch 검색) |
| [frontend](https://github.com/Social-Agent-Library-Management/frontend) | 에이전트 4개 하네스(해석→설계→구현→QA)로 디자인 시스템을 구현한 웹 화면 |
| [qa](https://github.com/Social-Agent-Library-Management/qa) | Slack 자연어 요청을 통해 QA를 분석하고, 검증 AI가 기획서·디자인 근거(RAG)로 판정해 테스트 영상으로 회신하는 QA 서비스 |
| [deploy](https://github.com/Social-Agent-Library-Management/deploy) | 인터넷이 없는 윈도우 PC에서 실행할 수 있도록 묶는 오프라인 배포 패키지 빌더 |
